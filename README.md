# SFMC_MCI_Expressions_Examples
Salesforce Marketing Cloud Engagement, Intelligence Reports Advanced, MCI, Datorama, Expressions examples

This repository exists because Salesforce help files are unhelpful to users that are unfamiliar with the syntax MCI uses to build expressions for Custom Dimensions and Custom Metrics.

Will try to put as many use case examples as I can because I am figuring out how to do this and it may be of use to someone else who has the same questions about this poorly documented SFMC Engagement analytics feature.

In your SFMC environment, if Intelligence Reports Advanced is enabled, this is where to start:

Analytics Builder > Intelligence Reports > Setup >

Connected Data Extensions --> add a data extension table to run a report on, have at least one field that is common to SFMC's native report tool such as JobID or SubscriberKey.

All the write-ups will be 'Commits', this is just the style of how I write things on GitHub.
